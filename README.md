## SHARLY Home - Home Assistant Integration

SHARLY Home is a custom Home Assistant integration that connects Home Assistant with the SHARLY ecosystem.

## Features

- Home Assistant integration for the SHARLY ecosystem
- MQTT-based communication
- Native Home Assistant entities and services

## Documentation

End-user documentation is available in the [GitHub Wiki](https://github.com/ReMi-HSBI/sharly-home-connector/wiki).
